# Changelog

## 0.1.0

- Declarative `twelf.toml` and `sources.cfg` generation
- Offline registry, vendor, lockfile (`twelf-pm.lock`)
- Namespace conflict detection and optional prefix rewrite
- `build`, `check`, `verify`, `tree`, `doctor`, `doc`, `latex`
- Lockfile checksums, `--locked`, SemVer ranges
- Debug tree / `--json`, timings, structured exit codes
- LSP stdio (COMPLETE, DEF, HOVER, SYMBOLS, DIAG)
- Templates, badges, git hook, shell completion
- Example: neuroasm (30 Twelf modules)
